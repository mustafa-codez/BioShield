
# 🧬 BioShield

**BioShield** is a simple web demo that turns passwords into DNA-style encrypted code.  
Built with **HTML, CSS, and JavaScript**, it features a modern glassmorphism design and glowing animations.

### 🚀 Features
- Converts letters into DNA pairs (A→AT, B→CG, etc.)
- Real-time encryption output
- Responsive neon-glow interface
